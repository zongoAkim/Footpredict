# Footpredict

Application de prédiction de résultats de matchs de football basée sur React, TypeScript et Tailwind CSS.

## Fonctionnalités

- Interface simple avec historique Domicile/Extérieur
- Affichage de données match par match
- Interface responsive (mobile et desktop)
- Utilisation de Next.js (App Router)

## Installation

```bash
npm install
npm run dev
